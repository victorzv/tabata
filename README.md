# Табата Таймер — PWA

Прогрессивное веб-приложение для интервальных тренировок по методу Табата.

## Возможности
- Настройка списка упражнений (добавить / удалить / переименовать)
- Выбор количества раундов: 2 / 4 / 6 / 8
- Звуковые сигналы (старт, отдых, обратный отсчёт, финиш)
- Работает офлайн после первого открытия
- Устанавливается на экран телефона как приложение

## Запуск через GitHub Pages

1. Создай репозиторий на GitHub (например: `tabata-timer`)
2. Загрузи все файлы (`index.html`, `manifest.json`, `icon.svg`, `sw.js`)
3. Зайди в Settings → Pages → Source: main branch
4. Через ~1 минуту сайт будет доступен по адресу:
   `https://ВАШ-НИК.github.io/tabata-timer/`
5. Открой эту ссылку в Chrome на Android
6. Нажми "Добавить на главный экран" — готово!

## Локальный запуск
Нужен любой HTTP-сервер (не просто открыть файл):
```
python -m http.server 8080
```
Затем открой http://localhost:8080
